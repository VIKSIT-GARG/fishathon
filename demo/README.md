# PanelCast demo

- [Watch or download the video](PanelCast-Drama3-Demo.mp4)
- [Preview the cursor animation](cursor-preview.gif)

The 76-second video is 1920 × 1080 at 30 fps, with H.264 video and 48 kHz stereo AAC audio. The standalone character performance is a 48 kHz, 24-bit stereo WAV.

Both the presenter narration and the two-character scene were generated with Fish Audio's **drama-3** model. The recording demonstrates the included comic becoming an original story, with Grandpa and Kid performing “The Case of the Ghost Cat.”

The edit reuses the recorded app clips, shortens processing waits, and retimes playback for the new audio. An editorial cursor adds eased movement, a trailing glow, click ripples, animated callouts, and camera follow. The source sketch stays pinned, and word timestamps drive the captions, speaker highlights, and comic-panel accents.

The original recording predates the Drama 3 audio upgrade, so the original model selector may show the earlier model. The new performance player and overlays identify the Drama 3 master used in this video. Adobe Express's connector was consulted, but it did not expose the required MP4 import/export workflow; the final effects were rendered locally.

The encoded soundtrack measures approximately −16 LUFS integrated and −1.9 dBTP. The cursor motion edition preserves the earlier Drama 3 edition's audio packets exactly. The generated scene transcription matches all 45 script words.

Only the finished deliverables are included here. API keys, temporary renders, local environment files, and machine-specific asset links are excluded. See the project README to run the application with your own keys.
